# BrightLearn AI Course Assistant

A mini Generative AI application that answers questions about fictional BrightLearn online courses using a verified knowledge base.

The project was developed as part of the **Big Brains Generative AI Internship — Day 16 Mini Project**.

## Project Objective

The objective of this project is to demonstrate how multiple Generative AI concepts can be combined to build a useful and reliable course-information assistant.

Users can ask questions about:

- Available courses
- Course duration
- Technologies covered
- Certificates
- Email support
- Refund policies

## Main Features

- Natural-language question answering
- Google Gemini API integration
- Fictional BrightLearn knowledge base
- TF-IDF-based knowledge retrieval
- Prompt engineering
- Structured response handling
- Knowledge-source identifiers
- Safety fallback
- Hallucination prevention
- Gradio web interface
- Five application test cases

## Application Workflow

1. The user enters a course-related question.
2. The application compares the question with the knowledge base.
3. Relevant knowledge records are retrieved using TF-IDF similarity.
4. The retrieved information is provided as context to the Gemini model.
5. The model generates an answer using the supplied information.
6. The application displays the answer, status and source identifiers.
7. If information is unavailable, the guardrail prevents the application from inventing an answer.

## Test Cases

The application was tested with the following questions:

1. Which course is suitable for a Python beginner?
2. How long is the Python Basics course?
3. What technologies are taught in Web Development?
4. Can I receive a refund after buying a course?
5. Who is the founder of BrightLearn?

The unsupported founder question was handled safely with the response:

> I don't have enough information to answer that.

## How to Run

1. Download or open the notebook in Google Colab.
2. Install the required Python libraries.
3. Add your Gemini API key to Google Colab Secrets as `GEMINI_API_KEY`.
4. Run all notebook cells in order.
5. Open the Gradio link generated by the final application cell.
6. Enter a course-related question and view the answer, response status and sources.

## API Key Security

The Gemini API key is not stored in this repository. Users must add their own key securely through Google Colab Secrets.

Never publish API keys in notebooks, screenshots or public repositories.
